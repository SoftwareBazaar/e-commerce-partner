# 🔍 How to Find OAuth Consent Screen

## You're in Google Cloud Dashboard

From where you are now, follow these steps:

### Step 1: Look at the Left Sidebar

You should see a menu on the left with options like:
- Cloud overview
- Solutions
- Recently visited
- Products
- Billing
- IAM & Admin
- Marketplace
- APIs & Services ← **CLICK THIS**
- Compute Engine
- Kubernetes Engine
- Cloud Storage
- Security
- BigQuery
- Monitoring
- View all products

### Step 2: Click "APIs & Services"

This will expand a submenu

### Step 3: Look for "OAuth consent screen"

In the submenu under "APIs & Services", you should see:
- Library
- Credentials
- **OAuth consent screen** ← CLICK THIS
- OAuth consent screen
- API keys
- Service accounts

### Step 4: You'll See the Consent Screen

Once you click "OAuth consent screen", you'll see:
- App name field
- User support email
- Developer contact
- App logo

### Step 5: Click "EDIT APP" button

This will let you edit the app name

### Step 6: Change App Name to "NeuroAlgo"

Update:
- **App name:** NeuroAlgo
- **User support email:** neuroalgoforexedge@gmail.com
- **Developer contact:** neuroalgoforexedge@gmail.com

### Step 7: Save

Click **SAVE AND CONTINUE**
