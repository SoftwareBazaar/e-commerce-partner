━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

401 Unauthorized error is NOT caused by API key

It's caused by RLS (Row Level Security) policies

RLS policies control who can access data
Without proper policies, access is denied

❌ RLS policies don't allow public access
❌ That's why you get 401 Unauthorized


THE FIX (5 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to Supabase Dashboard
   https://supabase.com/dashboard/project/zowfbftptnkypdwsnbkh

2. Click: SQL Editor

3. Click: New Query

4. Paste this SQL:

   -- Enable RLS
   ALTER TABLE newsletter_subscribers ENABLE ROW LEVEL SECURITY;

   -- Allow public SELECT
   CREATE POLICY "Allow public SELECT"
   ON newsletter_subscribers
   FOR SELECT
   USING (true);

   -- Allow public INSERT
   CREATE POLICY "Allow public INSERT"
   ON newsletter_subscribers
   FOR INSERT
   WITH CHECK (true);

5. Click: Run

6. Should see: "Success" message

7. Test newsletter subscription


WHAT THIS DOES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Enables RLS on newsletter_subscribers table
Allows public to check if email exists (SELECT)
Allows public to add new subscriber (INSERT)
No restrictions - everyone can access
