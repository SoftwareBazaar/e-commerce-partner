## What You Can Do

### Add a Product
1. Go to Admin Panel
2. Click "New Product"
3. Fill in details:
   - Name: "My EA"
   - Price: $99
   - Upload image
   - Add description
4. Click "Create product"
5. Product appears on marketplace

### Upload Images
- Click "Upload Image" button
- Select from computer
- Or paste URL

### Manage Prices
- Click product to edit
- Change buy/rent price
- Click "Save changes"

### Create Blog Post
1. Go to Blog tab
2. Click "New Post"
3. Write content
4. Upload cover image
5. Click "Save post"
6. Check "Published" to make live

### View Bookings
- Go to Bookings tab
- See all customer bookings
- Update status (pending → confirmed → completed)

### View Orders
- Go to Orders tab
- See all purchases
- Update status (pending → paid → delivered)

### View Messages
- Go to Messages tab
- See all contact form submissions
- See newsletter subscribers
